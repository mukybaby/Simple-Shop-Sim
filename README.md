For a more detailed version of the program, go to https://mintlify.wiki/mukybaby/Simple-Shop-Sim.

This should work in all python versions in the future. If at some point there is an error with the syntax, this was created in 2.14.4.
NO Python libaries, besides the built in ones, are used or are required to run this game.

If you want to add your own items or people, use customer_names.json and items.json using the formats list[str] for customer_names.json, and list[tuple[str, int]] for items.json.

If you want to contribute to the project, fork or make a pull request at www.github.com/mukybaby/Simple-Shop-Sim/. All accepted pull request authors will be added to CREDITS.md based on their Github username at the time. There will also be the url for the merge next to their name. If there is not, that means they are either a play tester, or contributed a lot.
